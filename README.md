# NoteMd

本地优先的 Markdown 桌面阅读、编辑软件。MIT 开源，为 Windows 优先设计。

目标：接近 Typora 的即时渲染体验，同时原样保留空白行，用相对路径管理图片，默认显示文档目录，并提供有序的本地文件库。
