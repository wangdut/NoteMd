# NoteMd 设计

## 编辑内核决定

MarkText 的 Muya 是 DOM/块树驱动的富文本内核。直接复用整个内核会同时继承其空白段落归一化与大量 UI 耦合，恰好触及本项目最重要的改动。NoteMd 采用 CodeMirror 6 保存原始 Markdown，在其上实现即时格式与块预览；复用 MarkText 可分离的 Markdown 扩展和工具，并记录每个文件的来源及改动。这样连续空行、未知语法和用户原有格式不会因打开/保存而丢失。

渲染使用 Marked、KaTeX、代码高亮及 DOMPurify。0.2 取消活动块显露源码：正文通过行/内联装饰直接编辑，代码隐藏围栏但正文可编辑，图片/公式/表格保持稳定节点。公式和图片属性在独立面板编辑；源码模式关闭装饰，阅读模式完整排版。CodeMirror 处理源文档、历史、选择、中文输入法与搜索；独立换行映射保留混合 CRLF/LF。

## 应用架构

- Electron 主进程：文件库、路径约束、原子写入、图片导入、设置、系统对话框、回收站、原生菜单与导出。
- 隔离 preload：窄范围 IPC API，不给渲染器 Node 或任意系统执行能力。
- React + TypeScript：工具栏、目录、文件库、设置、主题、命令分发。
- 纯函数/文件服务：单元测试覆盖丢数据风险和目录移动边界。
- Electron + Playwright：真实窗口验证键盘输入、空行、图片、文件与主题。

## 界面

顶部主题化菜单与轻量文档工具栏。左侧目录/文件库默认打开目录，可拖动调整宽度。正文最大宽度约 820px，宽屏保持阅读节奏。底部显示保存状态、路径、字数、行数及缩放。原生窗口控制区颜色同步主题。

浅色主题使用雾白底色、墨色文字、青绿色强调；深色使用蓝黑背景与薄荷青强调；暖纸使用米色背景与苔绿色强调。原创图标以折页和字母 N 的连续线条表达“文本与阅读”，图标源文件一并开源。

目录和正文缩放分别为 70–200% 与 70–200%。视图菜单可重置正文缩放；Ctrl+0 切换正文段落。专注模式隐藏侧栏；阅读/即时/源码按钮保持可发现性。

## 文件与图片

新用户文档库默认为 Windows 文档目录下的 NoteMd_Data，已有用户配置路径保持不变。侧栏以递归目录树显示库内文件，移动操作使用限定在库内的可视化目录选择器。

文件库为普通目录，排序保存在 `.notemd-order.json`。图片目录以日期时间序号命名，并含 `.notemd-assets.json` 标记，文件树自动隐藏这些目录。

首次粘贴分配同级目录，之后从文中引用寻找可复用目录。同一时间多次创建用独占 mkdir/文件写入保证唯一性。图片写入后才插入 Markdown，相对 URL 使用正斜杠与 URL 编码。

文档重命名保持资源路径；跨目录移动/另存为时复制本地图片，目标文件成功写入后再删除原 Markdown；保留原图片，避免破坏共享引用。外部图片、HTTP 图片保持引用不变。文件夹移动保持内部相对结构；禁止移动到子孙目录，检测外部相对引用并明确处理。

新建文档立即分配文件路径，避免未命名文档粘贴图片无处落盘。自动保存防抖，写入之前比较磁盘版本；发现冲突时保留内存草稿并显示选择。写入串行化，快速切换文档先保存当前内容。窗口关闭前保存失败则允许取消关闭。

## 安全与兼容

渲染 HTML 清洗、链接仅允许明确协议。Electron 使用 contextIsolation 与 sandbox，关闭 nodeIntegration。资源通过受约束的 IPC 数据 URL加载。错误显示可读提示。文件库操作不能通过 `..` 或符号链接越出授权目录。外部文档仅访问其同级资源。

## 验证

发行路径和软件版本来自 package.json，按 release/NoteMd-<版本号>/ 分离产物；便携包和目录包使用同一次构建。完整打包后自动生成发行说明、校验和清单，详见 releasing.md。

文件服务测试使用项目内临时目录；不接触用户真实文档。端到端测试使用隔离 userData 和文档库。检查保存重开空白行、同时间图片唯一性、移动后图片有效、外部改动冲突、路径越界拒绝、中文文本、任务列表、表格与公式、两处缩放独立以及主题持久化。
