# NoteMd 0.2 交互改版

## 问题与决定

0.1 的 live.ts 用选择范围决定整块是否渲染，并用鼠标高度猜源码行。点击导致整块 DOM 换成源码，无法稳定选择图片、公式或代码。0.2 取消此机制。

保留 CodeMirror 的原始文档与历史；实时模式永不因为选择变化暴露 Markdown 标记。普通文字在原位编辑，标题、强调、列表以行/内联装饰呈现。代码正文直接编辑，围栏隐藏；图片与公式始终渲染，显式工具打开路径/公式浮层。表格使用单元格编辑与行列工具。源码模式是查看完整标记的唯一入口。连续空行、CRLF、BOM、未知语法不经全篇重新序列化。

## 交互规则

- 标题双击或 F2 重命名，自动补 .md；Escape 取消，冲突报错，不覆盖同名文件。支持已授权的外部文档。
- 右键保留选区，提供撤销/剪切/复制/粘贴、标题、列表、格式、颜色、表格及节点相关操作。菜单和快捷键共用命令目录。
- Ctrl+Shift+7 有序列表，Ctrl+Shift+8 无序列表，Ctrl+Shift+9 任务列表。多行选择逐行应用；Enter 延续、空项 Enter 退出，Tab/Shift+Tab 缩进。
- 表格创建对话框指定正文行数与列数；单元格 Tab 移动，末格 Tab 添加一行；工具和右键支持前后增删行列、对齐。
- 图片单击显示选中框及上方绝对定位路径栏，图片保留。可编辑地址/说明、复制图片/Markdown、删除。公式单击只选中；显式“编辑公式”打开浮层，正文公式保持原位。
- 侧栏分隔线支持拖动、键盘方向键调整和双击复位；宽度持久化。正文和目录独立 Ctrl+滚轮缩放保持。
- 自绘菜单使用统一主题变量，窗口原生控制区颜色同步；Alt+F/E/P/O/V/T/H 访问菜单，Escape 关闭。

## 验证与分批提交

1. 复现并修复编辑层：点击不露标记、节点高度稳定、空行和历史保持。
2. 补齐命令、右键、表格、标题、侧栏与全窗口主题；真实 Electron 操作验证。
3. 复制用户文档到项目内隔离测试库，检查复杂语法、图片、保存重开；不修改原文档。
4. 类型/单元/Electron 检查通过后本地提交，打包 0.2，清理已确认过期的生成物。最后尝试推送，网络失败记录后保留本地成果。
