# NoteMd 产品需求与验收

版本：0.1 · 日期：2026-10-19 · 状态：进入实现

## 产品目标

给中文写作者、学生和开发者提供免费、开源、可迁移的 Markdown 桌面编辑器。以真实文件为数据源，不要求账号或网络服务。第一版优先 Windows，技术架构保留跨平台能力。

需求完整度自评 94/100：目标 29/30、功能 24/25、体验 19/20、约束 13/15、阶段 9/10。Windows、中文、自动保存及三套初始主题依据当前环境与需求确定；发行签名与跨平台安装器属于后续发行工作。

## 核心验收

1. 连续按 Enter 能创建连续空白行，编辑、切换文件、保存、重新打开均不折叠。源文本为唯一真相。
2. 编辑区单栏即时渲染；光标进入语法片段可编辑源文本，离开后显示格式。提供源码和阅读模式。中文输入法合成期间不重写文本。
3. 支持标题、段落、链接、图片、代码与高亮、引用、分割线、加粗、斜体、删除线、下划线、颜色、高亮、GFM 表格、有序/无序/任务列表、块/行内数学、脚注、内容目录。非法公式可编辑且不崩溃。HTML 必须清洗。
4. 粘贴图片到当前文档同级目录的 `YYYYMMDD-HHmmss-NNN` 文件夹；文中只写相对 URL。默认每个文档复用已有托管目录，目录重名自动递增。图片名不覆盖现有文件。文档改名不改变图片目录名。
5. 应用内跨目录移动/另存为，复制引用的本地图片到目标同级目录并重写路径；共享图片不删除。若操作失败，保留原文件与可恢复状态。系统外迁移需同时携带图片目录。
6. 默认侧栏为目录，层级、当前标题、点击定位正确。侧栏 Ctrl+滚轮与正文 Ctrl+滚轮独立缩放，设置持久保存。
7. 默认文件库为 Windows 文档目录中的 NoteMd；设置可选择新文件库，新建文件保存到所选目录。外部 Markdown 可通过系统对话框打开。
8. 文件库显示文件夹与 Markdown，隐藏托管图片目录。文档右键可在资源管理器查看图片目录；新建文件/文件夹、重命名、复制、移动、删除到回收站、复制路径、系统定位；拖动排序与跨目录移动。不能拖动文件夹进入自身后代，重名不得静默覆盖。
9. 文件/编辑/段落/格式/视图/主题/帮助菜单覆盖常见操作与快捷键。支持搜索替换、撤销重做、自动保存、字数统计、专注模式、HTML/PDF 导出。
10. 界面使用原创 NoteMd 图标、清晰层级和充足点击区域。浅色、深色、暖纸主题。支持键盘操作、可读的对比度和状态反馈。
11. 文件写入采用临时文件再替换；检测磁盘外部改动，不能直接覆盖。关闭窗口前处理未保存内容；恢复草稿保存于应用数据目录。
12. 独立 Git 仓库，按完成阶段提交；推送到 GitHub 时不包含私人文档、依赖、测试临时库、下载的整个上游仓库或密钥。

## 阶段

- A：设计、上游调查与许可记录。
- B：可测试的文件库、图片、保存和移动逻辑；核心 Markdown 渲染。
- C：桌面界面、即时编辑、菜单、主题与交互。
- D：真实 Electron 端到端验证、打包、使用说明与 GitHub 发布代码。

这些阶段都是当前任务的一部分。每阶段验证后提交，未验收项明确记录，不以界面占位符当成完成功能。

## 首版边界

不要求云同步、多人协作、插件市场、OCR 或商业签名证书。大型文档性能、更多图表语法和操作系统文件关联根据实际验证结果单独记录。不同 Markdown 软件对扩展语法的支持不一致，下划线和颜色采用可迁移的 HTML 标签。
